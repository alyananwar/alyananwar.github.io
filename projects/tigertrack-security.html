TigerTrack FERPA & API Security Review

The security and privacy section of TigerTrack's DegreeWorks API proposal to University of the Pacific IT.

FERPA OWASP API Top 10 Data flow mapping

Overview

Before TigerTrack can use real student data through the DegreeWorks API, the university needs to know how that data is handled. I wrote the security and privacy section of our proposal to UOP IT.

What I did

  • Mapped how student data moves through TigerTrack, from DegreeWorks to the app to the AI provider
  • Scored our controls against the OWASP API Security Top 10
  • Checked the design against FERPA requirements
  • Flagged that student GPA was being sent to an AI provider with no data agreement in place

Why it matters

Finding the GPA issue ourselves, before asking for real student data, was the most important part. The fix is to strip identifying data before any AI call.
