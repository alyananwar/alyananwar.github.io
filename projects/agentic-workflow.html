Agentic AI Developer Workflow

My development setup on the Claude Code CLI, with MCP servers, custom hooks, and an Obsidian knowledge base used as long-term memory.

Claude Code MCP Hooks Obsidian

Overview

Most of my projects get built with an agentic setup on the Claude Code CLI. I set it up so the agent has the right tools, follows my rules, and remembers what happened in earlier sessions.

What's in it

  • MCP servers: Playwright for driving a real browser and Context7 for up-to-date library docs
  • Custom hooks: linting and formatting run automatically after edits
  • Obsidian knowledge base: project notes, decisions, and blockers that the agent reads as persistent memory and RAG-style context across projects

Where it shows up

This workflow is how I ran a 16-step cleanup across all 6 of my public GitHub repos in about two hours. It checked for leaked keys, made a demo GIF for each project, found two projects crashing on install, and fixed a login bug in EasyReview. It started as a test of a topic I pitched for our Friday AI workshop: why prompt design matters.
